# **App Name**: Sport Center Hub

## Core Features:

- Schedule Display: Display the schedule of available courts, fields, and classes.
- Reservation System: Allow users to reserve courts, fields, or sign up for classes.
- Real-time Availability: Show real-time availability of resources.
- AI-Powered Recommendations: Suggest activities or classes based on user preferences and availability using an AI tool.
- User Account Management: Allow users to manage their profile, reservations, and preferences.
- Notifications: Send notifications for upcoming reservations, class reminders, or special offers.
- Contact information: List of sports center staff contact information

## Style Guidelines:

- Primary color: Blue (#42A5F5) to convey trust and activity.
- Background color: Light gray (#ECEFF1) for a clean, modern look.
- Accent color: Orange (#FFB74D) for interactive elements and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif, combining a modern look and a little warmth and personality.
- Use sport-related icons to represent different activities and facilities.
- Clean and structured layout for easy navigation and information access.
- Subtle animations and transitions for a smooth user experience.
